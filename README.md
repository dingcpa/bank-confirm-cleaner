# 銀行電子函證清洗工具

純前端網頁工具:將銀行函證系統(財金資訊公司)回覆的原始 xlsx 檔,拖曳上傳後自動清洗彙整為會計師查核用的「銀行存款明細表」與「銀行借款明細表」Excel(含匯率換算、合計公式)。

**線上使用:** https://dingcpa.github.io/bank-confirm-cleaner/

- 所有解析與產出皆在瀏覽器端完成,檔案不會上傳到任何伺服器
- 匯率自動抓取台灣銀行牌告匯率(可手動覆寫)

此 repo 僅供 GitHub Pages 部署;開發正本在 private repo `bank-confirm-cleaner-dev`,更新時將最新 `index.html` 複製過來 commit 即可。
